MOVIE RECOMMENDATION ENGINE

WE'LL be building a recommendation system that suggests movies based on user preferences and similarities between movie attributes.

OUR FIRST FEATURE:-
Display a searchable collection of movies.
HOW WE WOULD APPROACH THIS:-
We'll load a file that matches movie IDs to their titles. This helps us show the actual movie names instead of just numbers, for which we will be using a CSV file to store this data.(geeksforgeeks)

OUR SECOND FEATURE:-
Allow users to select favorite movies or genres. 
HOW WE WOULD APPROACH THIS:-
Filter Movies with Enough Ratings and prioritize them on the prescribed user's timestamp accordingly even based on previous data that is used to train the model.

OUR THIRD FEATURE:-
Recommend at least five movies based on preference.
HOW WE WOULD APPROACH THIS:-
We have joined the correlation data with our ratings dataframe and Filter movies that have more than 100 ratings for more reliable recommendations. We can also see how many ratings each movie has. Movies with more ratings are more important when we make recommendations.

OUR FOURTH FEATURE:-
Display the reason why each movie was recommended.
HOW WE WOULD APPROACH THIS:-
Content-based filtering: Content-based filtering recommends items based on the features of the items and the user's past preferences. For example, if a user likes action movies the system will recommend other action movies based on genres, actors or directors.

OUR FIFTH FEATURE:-
Prevent already selected movies from appearing as recommendations.
HOW WE WOULD APPROACH THIS:-
Collaborative filtering: Collaborative filtering makes recommendations based on user's past behavior and similar decisions made by other users to predict items user may be interested in. For example, if User A likes movies X and Y and User B likes Y and Z then system might recommend movie Z to User A.
